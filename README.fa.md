## ⚡ راه‌اندازی سریع (Quickstart)

```bash
# نصب و اجرای مستقیم از طریق NPX
npx @alwkala/tidyfactor-htmx
```

یا فراخوانی مستقیم در دستیار برنامه‌نویسی (*Google Antigravity, Claude Code, Cursor, Codex*):
```text
/tidyfactor-htmx
```

## 📋 ماتریس دستورات اصلی

| دستور | هدف و نتیجه | جریان کاری (Workflow) |
|---|---|---|
| `/brief` | Diseño de arquitectura de fragmentos hypermedia | `workflows/brief.md` |
| `/init` | Configuración de HTMX vendored localmente | `workflows/init.md` |
| `/fragments` | Generación de endpoints de fragmentos HTML | `workflows/fragments.md` |
| `/swap` | Configuración de transiciones y swapping | `workflows/swap.md` |
| `/forms` | Formularios reactivos con validación inline | `workflows/forms.md` |
